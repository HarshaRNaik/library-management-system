# Git Workflow

## Branching Strategy

- `main`: Stable version of the Library Management System.
- `feature/library-management-system`: Development branch for the Library Management System.

## Development Workflow

1. Make application or documentation changes on the feature branch.
2. Test and validate the changes.
3. Commit the changes with a meaningful commit message.
4. Push the feature branch to GitHub.
5. Merge the feature branch into `main` after validation.
